# Telegram-бот: диалог + RAG + ProxyAPI

Бот на **python-telegram-bot** (v21+) с **короткой памятью** (последние сообщения в RAM) и **долгой памятью** по документам (чанки → эмбеддинги `sentence-transformers` → **FAISS** на пользователя, индекс на диске). Ответы LLM идут через **ProxyAPI** (формат совместим с OpenAI **Chat Completions**), запросы — **aiohttp**.

## Требования

- **Python** 3.10+ (рекомендуется 3.11 / 3.12)
- Windows / Linux / macOS  
- Свободное место и трафик: при первом запуске загружаются веса эмбеддингов (`all-MiniLM-L6-v2`) и зависимости **torch**.

## Установка

```bash
cd путь_к_проекту
python -m venv .venv
.\.venv\Scripts\activate          # Windows
# source .venv/bin/activate       # Linux / macOS
pip install -r requirements.txt
```

Скопируйте конфигурацию:

```bash
copy .env.example .env           # Windows
# cp .env.example .env           # Linux / macOS
```

Заполните `.env`: как минимум `BOT_TOKEN` и `PROXY_API_KEY`.

## Переменные окружения

| Переменная | Описание |
|------------|-----------|
| `BOT_TOKEN` | Токен бота из [@BotFather](https://t.me/BotFather) |
| `PROXY_API_KEY` | Ключ ProxyAPI |
| `PROXY_API_URL` | Базовый URL API (по умолчанию `https://api.proxyapi.ru/openai/v1`) |
| `DEFAULT_MODEL` | Модель для чата (например `gpt-4o-mini`) |

Остальные параметры см. комментарии в [`.env.example`](.env.example): размер чанков, лимит файла, таймауты Telegram и т.д.

**Важно:** значения из `.env` загружаются из файла рядом с `bot.py` с приоритетом над переменными ОС (`override=True`), чтобы не «залипал» старый токен в системе.

## Запуск

```bash
python bot.py
```

Одновременно должен работать **только один** процесс с данным `BOT_TOKEN`, иначе Telegram вернёт **409 Conflict** на `getUpdates`.

## Команды в чате

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие и краткая инструкция |
| `/help` | Справка |
| `/clear` | Очистить историю диалога (короткая память) |
| `/cleardoc` | Удалить документ и векторный индекс (и файлы на диске) |
| `/stats` | Статистика памяти и текущая модель |
| `/model <название>` | Сменить модель LLM для пользователя |

Поддерживаемые документы: **PDF**, **DOCX**, **TXT** (лимит размера задаётся в `.env`). После отправки файла текст извлекается, режется на чанки и индексируется в FAISS.

## Файлы и логи

- Данные пользователей: каталог **`data/users/<user_id>/`** (`vectors.faiss`, `meta.json`).
- Лог по умолчанию: **`bot.log`** в корне проекта.

## Частые проблемы

- **409 Conflict** — запущено два экземпляра бота с одним токеном; остановите лишнее.
- **ConnectTimeout / getaddrinfo (11001)** к `api.telegram.org` — проблемы сети или DNS; при необходимости VPN или другой DNS.
- **Первый запуск долгий** — скачиваются PyTorch и модель эмбеддингов; это нормально.

## Безопасность

Не публикуйте `.env` и не коммитьте секреты. При утечке токена перевыпустите его в BotFather и обновите ключи в ProxyAPI.
